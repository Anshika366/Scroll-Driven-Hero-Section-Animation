# 🏎️ Scroll-Driven Supercar Hero Section Animation

An ultra-modern, high-performance interactive web experience featuring scroll-driven animations, real-time vehicle telemetry stats, procedural Web Audio engine sound synthesis, and smooth motion dynamics.

Built with **React 19**, **GSAP ScrollTrigger**, **Lenis Smooth Scroll**, and **Tailwind CSS**.

---

## ✨ Features

- **📜 Scroll-Driven Supercar Motion:** Smooth progress-based vehicle movement along an SVG track synchronized with page scroll depth.
- **⚡ Real-Time Telemetry HUD:** Dynamic Speedometer (0 – 320 KM/H), Gear Shift Indicator (Gears 1 – 6), Tachometer (RPM), and G-Force meter.
- **🔊 Web Audio Engine Sound Synthesizer:** Real-time dual-oscillator engine sound that dynamically adjusts pitch and volume based on scroll velocity and rev triggers.
- **🎨 Interactive Customizer:** Live color theme switcher (Neon Green, Hyper Red, Cyber Blue, Solar Gold) and Drive Mode selector (Comfort, Sport, Track).
- **📍 Aerodynamic Checkpoints:** Interactive hotspots displaying specs (Downforce, Cd Drag, Power-to-Weight ratio, Carbon Chassis).
- **💨 Dynamic Motion Trail & Particle Effects:** Real-time SVG neon trail fill behind the supercar and speed-responsive background grid particles.
- **📱 Fully Responsive:** Optimized for Mobile, Tablet, and Desktop displays.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React 19 + Vite
- **Animations & Scroll Engine:** GSAP 3 (ScrollTrigger) + Lenis Smooth Scroll
- **Styling:** Tailwind CSS + Custom Glassmorphism UI
- **Audio Engine:** Web Audio API (Sawtooth/Square Oscillators & Biquad Filters)
- **Icons:** Lucide React

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Anshika366/Scroll-Driven-Hero-Section-Animation.git
   cd Scroll-Driven-Hero-Section-Animation
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

Open `http://localhost:5173` in your browser to test live.
